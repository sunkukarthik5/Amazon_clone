# 🛒 Amazon Clone

A simple **Amazon Clone** built using **HTML and CSS**, replicating the look and feel of the original Amazon website.  
This project focuses on frontend design — layout, styling, and responsiveness.

---

## ✨ Features

- 🏠 Homepage layout similar to Amazon  
- 🔍 Search bar & navigation header  
- 🛍️ Product cards with hover effects  
- 📦 Footer and multiple sections  
- 📱 Responsive design for mobile and desktop  

---

## 🧰 Technologies Used

- **HTML5**
- **CSS3**
- **Font Awesome (for icons)**
